= Agent Heights iOS — Capacitor + RevenueCat + AdMob

== Overview

Agent Heights ships as a native iOS app via Capacitor, wrapping the existing
Vite-built web client (Phaser 3 + DOM HUD) as a WKWebView app. The server stays
on Railway. Three monetization systems operate in parallel:

[cols="1,1,2,2"]
|===
| System | Provider | Purpose | Shipaton Award

| In-App Purchases | RevenueCat | Subscriptions + entry fee + asset upgrades | Best Game, Grand Prize
| Rewarded Ads | Google AdMob | Watch ad → free entry fee / inference credit | HAMM Award ($20k)
| Web Payments | Stripe | Subscriptions on desktop web | Funnel Vision Award
|===

== Architecture

=== Monetization Flow (iOS)

[source,text]
----
User opens app
  → Auth overlay (email/password, Google, GitHub, Apple Sign-In)
  → Payment overlay:
     [Enter for 99¢]            ← RevenueCat IAP
     [▶ Watch Ad to Enter Free]  ← AdMob rewarded ad
     [Subscribe $3.99–$19.99/mo] ← RevenueCat IAP
  → Free-tier user hits usage cap:
     [▶ WATCH AD]               ← AdMob rewarded ad (inference_boost)
     [Subscribe to continue]     ← RevenueCat IAP
----

=== Rewarded Ad Reward Types

[cols="1,1,1,1"]
|===
| Reward Type | Amount | Daily Limit | Effect

| `entry_fee` | 1 | 5/day | Unlocks entrance (marks `entrance_paid=true`)
| `usage_credits` | 50 | 5/day | 50 usage credits via negative `api_usage_records`
| `agent_hire` | 1 | 5/day | Free agent hire token
| `inference_boost` | $0.05 | 20/day | Inference credit via negative `api_usage_records`
|===

The `inference_boost` type is the core of the HAMM Award pitch: ad-supported
free inference. Users watch ads to keep their agents working instead of paying.

=== Conversion Funnel

[source,text]
----
Free (ads, 20/day max) → $0.99 entry fee (no ads) → $3.99/mo starter → $19.99/mo pro
----

== iOS Feature Flags

Disabled on native iOS via `isFeatureEnabled()` in `client/src/platform.ts`:

[cols="1,1"]
|===
| Feature | Reason

| `cdpSolana` | Crypto not allowed on App Store
| `crossmintWallet` | Crypto not allowed on App Store
| `premiumMarketplace` | Depends on crypto infrastructure
| `screenShare` | WKWebView limitation
| `webcam` | WKWebView limitation
| `voice` | WebRTC not supported in WKWebView
| `monacoEditor` | Too heavy for mobile, IDE bridge not relevant
| `stripeCheckout` | Use RevenueCat IAP instead
|===

== Environment Variables

[cols="1,1,1"]
|===
| Variable | Scope | Purpose

| `REVENUECAT_SECRET_KEY` | Server | RevenueCat REST API verification
| `VITE_REVENUECAT_PUBLIC_KEY` | Client | RevenueCat SDK initialization
|===

Both are set in `.env` (gitignored). Public key is bundled into the client
build via Vite's `import.meta.env`.
